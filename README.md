# VPNGate Bridge

Work in progress. This repository is not yet deployable and does not provide a proxy or subscription service. Only discovery is implemented; candidates are untrusted and have not been probed or verified as residential.

Run tests: `python3 -m unittest discover -s tests`.

VPNGate is operated by volunteers and its [logging policy](https://www.vpngate.net/en/about_abuse.aspx) describes connection and destination metadata logging. A non-hosting IP classification does not prove an address is residential or that service will be stable.

The pure selection module checks country, hosting classification, exit uniqueness, three latency measurements and a persistent expiring subnet blacklist. The `probe` module can measure a running SOCKS gateway with curl and classify its exit via ipapi.is, but no gateway orchestration exists yet. Its score caps latency at 1 s, measured throughput at 100 Mbit/s and uptime at 7 days; requiring all three probes to succeed makes the stability component constant for eligible candidates. These normalization choices are provisional.

The OpenVPN parser pins the relay IP and accepts only a limited set of directives and inline PEM blocks. It is not a network sandbox: firewall, DNS and IPv6 leak protection must be implemented and independently tested before running candidates.

The probe requires curl, an isolated SOCKS5 gateway, and either an [ipapi.is API key](https://ipapi.is/developers.html) with `is_datacenter` data or the keyless [WhatsMyIP.now API](https://whatsmyip.now/api). It checks the exit three times through the SOCKS gateway, classifies that IP over HTTPS, then downloads 1 MB via Cloudflare for a speed sample. Classification errors and missing fields fail closed; the key is not passed to curl. The probe and provider integration have not been tested against a live VPNGate tunnel.

The experimental gateway image can be built with `docker build -f gateway/Dockerfile -t vpngate-gateway .`. It is deliberately not wired to a public service: it requires a read-only `/config/client.ovpn`, `VPN_SERVER_IP`, `NET_ADMIN`, `/dev/net/tun`, an isolated Docker network and no published SOCKS port. It blocks direct egress and IPv6 before starting OpenVPN, and starts SOCKS only after a tunnel route appears. It has not yet been validated against a real relay, a full tunnel outage, or adversarial network conditions; do not deploy it.

`vpngate_bridge.bridge.build_config` generates VLESS over WebSocket with TLS and Hysteria2 listeners with per-country SOCKS routes and a reject fallback. This is configuration generation only: credential synchronization, traffic enforcement and subscription generation are not implemented. A SQLite port registry preserves assignments, but is not yet connected to orchestration. The gateway currently supports TCP SOCKS CONNECT only; UDP destination traffic, including DNS over UDP, is not yet supported. Server-certificate purpose is checked, but the VPNGate relay's certificate identity is not pinned to a hostname; do not rely on it against active interception.

`scan()` can use `DockerGateway` to start one temporary, CPU/memory-limited container at a time, probe each candidate, remove the container, and return country winners subject to a country cap. It requires a local Linux Docker engine, a prebuilt gateway image, an existing Docker bridge network, and optionally an ipapi.is key. Keyless WhatsMyIP.now lookups are limited to 30 per minute per source IP; rate limits and unknown classifications reject candidates. These functions do not publish gateways: winners must be started and revalidated before they can serve traffic. A local Docker bridge IP is not reachable from a macOS Docker Desktop host. Docker is a privileged control interface; run the controller only with a trusted local daemon.

`vpngate_bridge.subscription.subscription` emits base64-encoded VLESS and Hysteria2 links for a user already present in every generated inbound. Base64 is not encryption: subscription contents contain client credentials. No authenticated HTTP subscription endpoint or expiry/traffic enforcement exists yet, so do not expose generated contents.

For a Linux-only evaluation scan, build the gateway image, create a dedicated Docker bridge network, and run `python3 -m vpngate_bridge --network vgb-private --state-dir ./state --max-countries 8`. The scan can take a long time and contacts third-party IP and speed-test services. `state/scan-results.json` is an atomic, private candidate report, not a list of running gateways; saved ports are not checked against unrelated services already bound on the host. Revalidate before any activation. To use ipapi.is instead of the default classifier, supply `IPAPI_IS_KEY` through the environment.
